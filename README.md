# Mystrix CFW

Open-source custom firmware for Mystrix.
Mystrix CFW is an alternative firmware focused on stability, responsive pad input, customizable LED behavior, and a simple workflow for everyday use.

## Features

- Dual USB MIDI ports
- 8×8 pressure-sensitive pad input
- LED brightness control
- Custom velocity palettes
- Web-based palette editor and uploader
- Apollo Studio support

## Firmware

The latest firmware is available from the Releases page.

Download the latest `.uf2` file and copy it to the `MYSTRIX-DFU` drive after entering DFU mode.

## Web Editor

The Mystrix Web Editor provides:

- Latest firmware release download
- palette editing
- Palette import / export
- palette upload
- Automatic Mystrix MIDI detection

## Compatibility

Designed for the Mystrix hardware created by [203 Systems](https://github.com/203-Systems).

Mystrix CFW is an independent alternative firmware and is not affiliated with or officially maintained by 203 Systems.
